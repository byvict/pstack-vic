# Converge

Converge is what happens to a PR after the Raiz certifies it and ends: on Victor's Mac, not in a cloud. The [Pré-PR](pre-pr.md) playbook publishes the Certificado and arms auto-merge with `--pending`; GitHub merges when the required checks pass, and the sweep merges the PR that GitHub leaves open 5 minutes after they passed. Three launchd jobs cover what the Raiz cannot see after it ends. Read the [contract](../references/converge-contract.md) and [`docs/pre-pr.md`](../../../docs/pre-pr.md). The Cursor cloud owner, its `start.ts` launcher and the three Automations are retired; 0.5.0 removes their code.

## Three jobs

| Job | Runs | Model | Does |
|---|---|---|---|
| `com.pstack.converge-sweep` | `converge-local tick --job sweep`, every 10 min and on a wake | none | Runs `converge-sweep` on every configured repository: arms each certified PR on trunk without a hold, disarms a held or refused one, and runs the arm command again on an armed certified PR that GitHub reports as mergeable and left open 5 minutes after its required checks passed, which merges it. Covers a stack child retargeted after its parent merged and a PR left unarmed on a red trunk. Then runs the `postMerge` block of each repository's trunk contract once per new trunk commit, oldest first, after that commit's push Tests passed, in a detached worktree of the commit: pstack-vic's tags the release, moves both parents and reinstalls these jobs. A red trunk commit notifies once: the one the `postMerge` queue waits on, or, without a block, the trunk tip. |
| `com.pstack.converge-raiz` | `converge-local tick --job raiz`, every 10 min and on a wake | the `converge raiz` row of the sheet | Lists the open PRs, skips drafts, held PRs, forks, leased branches and PRs whose author is outside the trusted list (the `gh` account plus `trustedAuthors`), classifies the rest (`repair`, `recertify`, `certify`, `respond`), holds a PR with work that someone outside the list commented on or reviewed, holds a PR that stalls, and launches one Raiz on the lowest PR with work to run [Catch-up](catch-up.md). |
| `com.pstack.converge-watch` | `converge-local tick --job watch`, every 60 s | none | Asks GitHub, with conditional GETs only, whether the open PR list, the trunk tip's check runs (with or without an open PR) or an open PR head's check runs changed, and wakes the jobs that care: the list wakes both, the trunk's checks wake the sweep, a head's checks wake the raiz job. A 304 costs no rate limit; it never launches a model and never writes to GitHub. |

`node <plugin>/skills/poteto-mode/scripts/converge/converge-local status` shows the configuration, the sheet row, `gh` and parent authentication, the leases, the ledgers and how each job's last tick ended. `node <plugin>/skills/poteto-mode/scripts/converge/converge-local run --repo OWNER/REPO --pr N` launches one attempt by hand through the same path, and `node <plugin>/skills/poteto-mode/scripts/converge/converge-local post-merge --repo OWNER/REPO --commit SHA` runs one trunk commit's `postMerge` by hand, whatever its record says. `node <plugin>/skills/poteto-mode/scripts/converge/converge-local install --when-idle` reinstalls the jobs once neither the sweep nor the raiz job runs, so the bootout kills no tick and no Raiz. `node <plugin>/skills/poteto-mode/scripts/converge/converge-local nudge` wakes the sweep and raiz jobs now, by leaving a file in each job's wake directory, instead of waiting for the interval: Pré-PR, Babysit and Shipping do it after releasing the lease, a tick that launched a Raiz does it for the next PR and for the sweep, and a PR opened by hand can get one too. The watch job does it within a minute for what changes on GitHub without anyone on the Mac: a Dependabot PR, a check that completes or turns red, trunk turning green, a hold label removed. Its first tick after `install` only stores what it read. An uncertified PR without a lease is certified once its tests check completed on the head, or 30 minutes after it opened; the lease, not the age, keeps the daemon off a branch a session is certifying. After the arm the daemon owns the PR: a red required check is `repair`; a conflict with trunk and every verdict refusal a new certificate cures (trunk policy moved, the verdict comment deleted or superseded) are `recertify`; a comment or review posted after the verdict, other than the flow's own notes, makes the sweep disarm and is `respond`, which answers it against the code and certifies again. Caps: two failed or three deferred attempts on a head, or six hours from the first attempt, apply the hold label with a comment and a macOS notification. So do an outsider's comment or review on a PR with work (at once), an armed PR that has not merged after two hours, and the same verdict refusal after an hour. After a deferred attempt, the next launch on that head waits 30 minutes. A Raiz that does not start, or ends without an outcome within two minutes, is a tick error and no attempt. After three launch failures on a head since its last recorded attempt, the PR waits an hour after the latest one; every tick that reaches it meanwhile reports the wait as an error and moves on to the next PR. A new head resets the counts, but a held PR stays skipped until the label is removed, which resets them too. Attempts are capped at two hours of wall time. A required check that concluded `neutral` or `skipped` counts as passing, as GitHub counts it: it opens no `repair`, and the arm accepts it.

The optional `postMerge.linear: true` final step reconciles explicit full `Pstack-Linear:` commit trailers after the exact certified PR head merges. It reads live acceptance and rollout sources through the configured native Raiz, publishes progress, and closes an issue only when independent cited assessments cover every obligation. Projects receive progress only. See the [Linear contract and activation instructions](../references/converge-contract.md#local-daemon), including native availability, retained-ledger retries, and `post-merge --dry-run`. Successful local commands are checkpointed before a Linear deferral. A source-only read or writer probe proves a component; installed-daemon delivery needs the released plugin path and native effect readback.

## Handoff from the local agent

There is none. The Raiz ends at the arm receipt of Pré-PR step 8, and so does the harness: never offer or rely on a desktop app's Auto-fix or CI monitor for an armed PR, whose push would skip the lease and the disarm and race a daemon Raiz. The session that opened the PR ends at that receipt and never waits for or polls the merge: what follows the merge belongs to the repository's `postMerge` block, which the sweep job runs. A session that must touch a PR branch the daemon may also touch takes the branch lease first (`converge-local lease`), which is what Pré-PR, Babysit and Shipping do, and wakes the daemon (`converge-local nudge`) right after releasing it.
