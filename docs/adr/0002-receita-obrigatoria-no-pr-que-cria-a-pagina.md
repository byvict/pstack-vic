# Receita obrigatória no PR que cria a superfície

Uma superfície que nenhuma Receita alcança deixava o veredito `INCONCLUSIVE` e o PR esperava Victor. Decidimos que, no Pré-PR, uma superfície sem Receita bloqueia o Certificado: a Receita entra no mesmo PR que cria a superfície, escrita pela Raiz ou delegada ao Autor. As alternativas eram publicar o Certificado com a lacuna nomeada e segurar o PR, ou aceitar a lacuna e certificar só com testes e revisão; as duas deixam a página sem verificação para sempre, porque depois do merge ninguém sabe mais o suficiente para escrever a Receita.
